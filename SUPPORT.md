# Support

| You need | Go to |
|---|---|
| How-to questions | [Docs](https://docs.weave.earth) · [Quickstart](https://docs.weave.earth/getting-started/quickstart) |
| A bug | [Open an issue](https://github.com/l1felabs/useweave/issues/new/choose) |
| A feature | [Request it](https://github.com/l1felabs/useweave/issues/new?template=feature_request.yml) |
| A security issue | [SECURITY.md](SECURITY.md) (private) |
| Enterprise support and procurement | eng@l1fe.ai |

Maintainers triage new issues within 2 business days.

When you file a bug, include the output of:

```sh
npx joinweave --version
~/.weave/bin/weave doctor --json
```
